CODEBOOK - Pima Indians Diabetes Database (diabetes.csv)
=========================================================

Source: Pima Indians Diabetes Database, originally collected by the National
Institute of Diabetes and Digestive and Kidney Diseases (NIDDK).
Public copy: OpenML dataset ID 37, https://www.openml.org/d/37
Archived copy used in this study: data/diabetes.csv in
https://doi.org/10.5281/zenodo.23527230

Records: 768 adult female participants of Pima Indian heritage, aged 21 years or older.
Columns: 9 (8 predictors + 1 outcome). One row per participant.


CATEGORICAL VARIABLE (recorded numerically)
-------------------------------------------
Outcome     Diabetes status (target variable)
              0 = Non-diabetic (500 records, 65.10%)
              1 = Diabetic     (268 records, 34.90%)


NUMERIC VARIABLES
-----------------
Column name                Description                                                   Unit        Range in file
Pregnancies                Number of times pregnant                                      count       0 - 17
Glucose                    Plasma glucose concentration at 2 hours in an oral            mg/dL       0 - 199
                           glucose tolerance test
BloodPressure              Diastolic blood pressure                                      mm Hg       0 - 122
SkinThickness              Triceps skinfold thickness                                    mm          0 - 99
Insulin                    2-hour serum insulin                                          muU/mL      0 - 846
BMI                        Body mass index (weight in kg / (height in m)^2)              kg/m^2      0 - 67.1
DiabetesPedigreeFunction   Diabetes pedigree function (score of genetic predisposition   unitless    0.078 - 2.42
                           based on family history)
Age                        Age                                                           years       21 - 81


ZERO-CODED MISSING VALUES
-------------------------
In this dataset a value of 0 is physiologically implausible for the variables below
and denotes a missing measurement. In this study these zeros were treated as missing
and imputed with KNN imputation fitted on the training partition only.

  Glucose          5 zeros
  BloodPressure   35 zeros
  SkinThickness  227 zeros
  Insulin        374 zeros
  BMI             11 zeros

A value of 0 in Pregnancies is a valid value (never pregnant) and is not treated as missing.
